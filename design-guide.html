02 — Typography

Skala Tipografi

Font tunggal: Inter (Google Fonts) — weight 400, 500, 600. Tidak ada ukuran lain di luar tabel ini.

Contoh Nama Properti CSS Dipakai pada
Polypipe Academy Display 30px 400 lh 38px Judul halaman Auth (Login, Register)
Referensi Setting H1 / Page Title 24px 600 lh 32px Judul halaman dalam page-header, nama user di Home
Calculator H2 / Card Title 20px 600 lh 30px Judul feature card di Home
Lupa Kata Sandi H3 / Section Title 18px 600 lh 28px Judul header sederhana (screen lupa, password)
Clamping Pipa H4 / Label 16px 500 lh 24px Judul setting card, modal title, teks button
Masukkan email Anda untuk reset password. Body 14px 400 lh 20px Deskripsi, sub-header auth, label input, teks modal
Panduan pengelasan pipa HDPE standar internasional Small 12px 400 lh 18px Sub-title card, greeting user, kontak welcome, coming badge
Splash · Login · Register XS / Nav 11px 500 lh 16px Label navigasi prototype (breadcrumb)
9:41 Status Bar Time 15px 600 ls -0.3px Waktu di status bar atas layar
Hanya tiga font-weight yang di-load: 400 (regular), 500 (medium), 600 (semibold). Jangan tambah weight lain agar bundle font tetap kecil. Tidak ada italic.
