## 2026-06-11 — Calculator Step Pages (Mobile User)

**Task**: Implementasi 3 halaman lanjutan setelah `calculator-result.html` mengikuti desain Figma node 80144-1364, 80144-1459, 80144-1558.

### File Dibuat / Diubah

| File | Aksi | Keterangan |
|---|---|---|
| `js/calculator-params.js` | BARU | Shared utilities: `calcWeldingParams`, `buildCycleSVGWithHighlight`, `formatCountdown`, `initProtoBanner` |
| `calculator-step1.html` | BARU | BEAD UP — tampilkan target tekanan (p1+pt) + ukuran bead (A_bead) + ilustrasi |
| `calculator-step2.html` | BARU | HEAT SOAK Fase 1 — instruksi kurangi tekanan dari p1+pt ke 0 bar + tombol OK |
| `calculator-step3.html` | BARU | HEAT SOAK Fase 2 — countdown timer heat soak, alarm 10 detik terakhir, "Batalkan Proses" |
| `calculator-result.html` | UPDATE | Tombol "Selanjutnya" → `calculator-step1.html` (was: `alert(...)`) |
| `js/config/page-status.js` | UPDATE | Tambah 3 entry baru: `calculator-step{1,2,3}.html` → `progress` |
| `CLAUDE.md` | UPDATE | Struktur direktori diupdate dengan file-file baru |

### Fitur yang Diimplementasi

- **Step 1 — BEAD UP**: Progress bar 1/5 hijau, nilai dinamis dari `calc_input` sessionStorage (`p1+pt` bar, `A_bead` mm), ilustrasi SVG penampang pipa + diagram siklus dengan fase t1 di-highlight oranye, navigasi Sebelumnya/Selanjutnya
- **Step 2 — HEAT SOAK Fase 1**: Progress bar 2/5 hijau, kartu instruksi kurangi tekanan (p1+pt → 0 bar dengan panah), tombol OK konfirmasi (state: normal → hijau ✓), diagram siklus fase t2 di-highlight, navigasi Sebelumnya/Selanjutnya
- **Step 3 — HEAT SOAK Fase 2**: Progress bar 2/5 hijau (sub-step Heat Soak), countdown timer HH:MM:SS dari durasi `t2s` (heat soak time computed), alarm pulsing merah + shake 10 detik terakhir, setelah timer habis muncul tombol "Selanjutnya", hanya "Batalkan Proses" (→ `calculator.html`)
- **Shared JS**: `js/calculator-params.js` di-`<script src>` di ketiga halaman — DRY, konsisten
- **Empty state**: semua halaman handle kondisi tanpa sessionStorage dengan link kembali ke kalkulator
- **A11y**: `role="progressbar"`, `role="timer"`, `aria-live="polite"`, `aria-label` per section, `aria-valuenow/min/max`
- **Animasi**: fade-in page, timer pulse (alarm), digit shake, OK button state transition
- **Proto banner**: `🧪 PROTOTYPE — Mock active` + segitiga status `In Progress`

### Data Flow

```
calculator.html → (submit) → sessionStorage('calc_input') → calculator-result.html
→ Selanjutnya → calculator-step1.html (BEAD UP)
→ Selanjutnya → calculator-step2.html (HEAT SOAK Fase 1)
→ Selanjutnya → calculator-step3.html (HEAT SOAK Fase 2 — timer)
→ Timer habis → "Selanjutnya" (step 4 belum tersedia)
```

### Catatan Integrasi

Halaman-halaman ini **read-only** — tidak ada API call, semua data dari `sessionStorage('calc_input')`.  
Saat BE siap untuk persist welding session:
1. Setelah `calculator-result.html` sukses → POST ke `/api/v1/welding-sessions` (simpan params)
2. Step pages bisa GET session by ID dari BE (ubah dari sessionStorage ke API call)
3. Hapus `sessionStorage('calc_input')` dependency, ganti dengan session ID di URL query param
