### Fitur yang Diimplementasi

- **Tabel 8 kolom**: Nama+email (user cell), No HP, Role (badge), Status (inline dropdown), Paket (free/premium/expired badge), Tanggal Daftar, Last Login (relative time)
- **Stat summary cards**: Total pengguna, Aktif, Suspended, Premium
- **Filter + Search**: search realtime (debounce 300ms) + filter Role, Status, Paket
- **Tambah pengguna**: modal form lengkap, validasi client-side, toast sukses/error
- **Edit pengguna**: modal pre-filled dari data existing, update data
- **Quick-change status**: dropdown inline di tabel, tanpa buka modal, dengan loading
- **Hapus pengguna**: modal konfirmasi dengan info user, hard delete
- **Mock 15 user**: campur admin/pengguna, active/nonaktif/suspended, free/premium/expired
- **Business rules enforce**: admin tidak bisa suspend diri sendiri, email unik, premium wajib expired date
- **A11y**: aria-modal, aria-label, aria-invalid, aria-live, aria-busy per semua interaktif
- **Loading skeleton + empty state + error state** — semua UI state hadir
- **Toast notifikasi**: sukses (hijau) + error (merah), auto-dismiss 3.5s
- **Banner**: `🧪 PROTOTYPE — Mock active` fixed top + segitiga status indicator
